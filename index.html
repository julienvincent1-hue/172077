Expédition Prosp'Auto

Ce fichier ne peut pas fonctionner dans cet aperçu.

Vous l'avez sans doute ouvert sur un téléphone ou directement depuis un message. Il faut l'ouvrir dans un navigateur Internet, sur un ordinateur :

  1. Enregistrez le fichier sur un ordinateur, par exemple sur le Bureau.
  2. Ouvrez-le d'un double-clic : il s'affiche dans Chrome, Edge, Firefox ou Safari.

Si vous n'avez qu'un téléphone, prévenez votre professeur : il vous donnera un autre moyen d'accès.
